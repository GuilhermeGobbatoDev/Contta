# Contta 💜

**Seu dinheiro. Seu controle.**

O **Contta** é um projeto de aplicação web para gerenciamento financeiro pessoal, desenvolvido com C# e .NET.

O objetivo é ajudar pessoas a organizar suas receitas e despesas, acompanhar seus gastos, planejar seu orçamento mensal e tomar decisões financeiras mais conscientes.

## Funcionalidades

### Em desenvolvimento
- Cadastro de despesas com descrição, valor, categoria e data.
- Validação dos dados financeiros.
- Listagem de despesas.
- Cálculo do total de despesas.
- Busca de despesas por ID.
- Exclusão de despesas.

### Funcionalidades planejadas
- Cadastro e autenticação de usuários.
- Registro de receitas.
- Edição e categorização de movimentações.
- Cálculo do saldo disponível.
- Planejamento do orçamento mensal.
- Sugestão de limite diário de gastos.
- Metas de economia.
- Relatórios e gráficos financeiros.

## Estrutura atual

O projeto está sendo organizado com separação de responsabilidades:

- `Models/` — classes que representam os dados financeiros.
- `Services/` — regras de negócio, validações e operações com despesas.
- `Program.cs` — ponto de entrada da aplicação atual.

Nesta fase, os dados são armazenados temporariamente em memória. A persistência em banco de dados será implementada futuramente.

## Objetivo do projeto

O Contta está sendo desenvolvido como projeto pessoal de aprendizado e portfólio, com foco em boas práticas de programação, orientação a objetos, desenvolvimento back-end e construção gradual de uma aplicação web.
